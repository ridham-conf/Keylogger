# Keylogger
Keylogger & Desktop Monitoring Tool|Monitoring & Security Logging Tool | Python, Network Security, API Integration

Developed a surveillance tool to analyze keylogging and screen-grabbing mechanics for educational threat analysis and security testing.

Implemented real-time keyboard event hooking using pynput to log user keystrokes with precise timestamps and auto-flush memory buffers.

Configured a background daemon thread with threading and Pillow to capture and stream in-memory desktop screenshots at 60-second intervals.

Engineered secure data exfiltration payloads over HTTPS using Discord Webhooks and custom payload formatting.
Languages & Libraries: Python, pynput, Pillow (PIL), requests, threading
